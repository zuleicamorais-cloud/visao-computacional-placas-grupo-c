# Visão Computacional — Placas Mercosul 🚗

Projeto de aprendizagem desenvolvido pelo Grupo C no curso de Visão Computacional da Arte dos Dados, com orientação do professor Alan.

## Objetivo

Desenvolver e avaliar uma solução de visão computacional para detectar placas veiculares no padrão Mercosul em imagens.

## Etapa atual

O projeto está em desenvolvimento, com foco na exploração das imagens e na validação dos recortes de placas.

O notebook inicial registra o trabalho exploratório de Zuleica. As próximas contribuições serão incorporadas conforme o avanço do grupo.

## Etapas previstas

- Explorar e organizar o conjunto de imagens.
- Verificar as anotações e os recortes das placas.
- Preparar os dados para treinamento, validação e teste.
- Treinar e avaliar um modelo de detecção.
- Analisar erros e propor melhorias.

## Tecnologias

- Python
- Google Colab
- Jupyter Notebook (`.ipynb`)
- Git e GitHub para controle de versões

Outras bibliotecas e ferramentas serão documentadas conforme sua utilização.

## Como acompanhar

Abra os arquivos `.ipynb` para visualizar os códigos, explicações e resultados registrados.

Para executar um notebook, abra-o no Google Colab e ajuste os caminhos de acesso aos dados conforme seu ambiente. As imagens e demais arquivos necessários podem depender de acesso separado.

## Versionamento

Cada avanço será registrado por meio de commits com mensagens que descrevam as alterações.

Para atualizar um notebook existente, mantenha o mesmo nome e caminho do arquivo, preservando seu histórico.
